Zylos Browser Remote

Use a dedicated Chrome profile, not your daily one. Since 0.2.0 there is no per-tab arming: the agent drives whichever tab matches the site you asked about — reusing one you already have open, or opening a new one — plus the tabs it opens itself. That is a wider reach than 0.1.x, so the separate profile matters more now, not less. Payment and account-settings pages are still refused by this extension regardless of what is asked, password fields still cannot be typed into, and arbitrary JavaScript is still never accepted — only structured actions (navigate, click, fill, snapshot, screenshot) on a selector you can see.
Ask the agent for its current domain — it is assigned by the platform and can change, so it is never hardcoded here. The path is always /browser-remote/ext. Over a tailnet instead, use ws://<tailnet-host>:3802/ext.
Shared secret from the relay. Stored in this profile's local extension storage.
