# Extension diagnostics

The owner enables diagnostic collection in the extension panel. Collection is
off by default. The extension keeps a bounded, expiring local ring of structured
events; disabling collection clears that ring. It does not collect page URLs,
content, selectors, typed text, credentials, or arbitrary error messages.

List browser endpoints with the existing status client. Retrieve one browser's
ring using its exact endpoint ID:

```sh
node scripts/diagnostics.js <endpointId> --after 0 --limit 100
node scripts/diagnostics.js <endpointId> --all --format ndjson --source executor --task 3
```

The CLI calls `POST /diagnostics` on the loopback agent lane. Its JSON body is
`{ "endpoint": "<endpointId>", "after": 0, "limit": 100 }`. `after` must be a
nonnegative safe integer; `limit` is 1 through 200. Both are optional. The relay
sends `diagnostics.get` over that endpoint's authenticated WebSocket connection
only when it advertises `diagnostics-v2`. No browser action or control grant is
required, including while a task runs or after it stops. The extension response
is checked and bounded to 256 KiB. The relay
does not store it in files or monitor traces.

Success returns schema version 2 with `enabled`, actual manifest `version`,
`epoch`, `events`, `nextCursor`, `highWater`, `oldestCursor`, `dropped`, `hasMore`,
`truncated`, `storageHealthy`, and `restartCount`. Events have `seq`, `at`,
`event`, `source` (`background`, `sidepanel`, `executor`) and `level`
(`debug`, `info`, `warn`, `error`). Optional task/operation IDs are local numeric
correlation IDs generated by the extension, not task text or external IDs.
Allowlisted methods, reasons, status, error kinds/codes, console argument counts
and socket close codes explain lifecycle transitions. Raw error messages,
stacks, console arguments, page data and arbitrary object fields are excluded.

The extension ring retains at most 1,000 events and 256 KiB for 30 minutes.
Use `--level`, `--source`, and `--task` for exact-match filtering. Filters advance
the scan cursor over nonmatching events as well. `--all` freezes the first
page's `epoch` and `highWater`, then fetches pages with that same snapshot bound.
New events remain for a later export. HTTP clients pass `epoch` and `through`
along with `after` for the same behavior. A changed epoch returns
`DIAGNOSTICS_RESET`; never silently continue a cursor in a new epoch.

Exports stop at 20 pages, 4,000 events, 1 MiB or a 30-second budget checked
between requests (one in-flight request may add up to ten seconds). JSON returns
events and snapshot metadata together. NDJSON starts with one `metadata` record
followed by `event` records. Neither format is written to disk automatically.
`complete` means the retained matching snapshot was exhausted with no reported
collection gap. It is false when collection is disabled, events were dropped,
storage is unhealthy, the worker restarted, pages remain, or export failed.
An `--all` export with `complete:false` exits nonzero while preserving available
events. This is not proof that every browser or JavaScript event was observed;
collection covers the instrumented execution chain only.

For a fresh reproduction, the owner can turn collection off and on, which
clears the ring and changes its epoch. Worker restarts are reported explicitly.
Changing the extension's relay URL or connection key disables collection and
clears its local buffer before the new recipient is saved. Previously fetched
copies held by an Agent or other tool are not retracted by local clearing.

Disabled collection succeeds with `enabled:false` and an empty event list.
Old clients return `DIAGNOSTICS_UNSUPPORTED`; disconnected clients return
`EXT_OFFLINE`. `EXT_TIMEOUT` means no answer arrived within five seconds.
Malformed replies return `BAD_DIAGNOSTICS_RESPONSE`. The CLI itself has a
ten-second HTTP bound. None of these errors automatically retries the request.

The agent lane remains bound to `127.0.0.1`. Never route it publicly. The public
extension lane retains its existing authentication and exposes only `/ext`.
